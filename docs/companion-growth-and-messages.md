# 寵物成長與外部訊息

開發版本：1.29.0；v1.28.2 不包含這兩項新功能。

## 成長

成功同步後，每個帳號只選一個固定週配額窗口計算實際觀察到的已用比例增量；
Claude 優先使用每週所有模型，其他來源依穩定窗口 ID 選擇。不相加五小時和每週、
也不疊加各模型配額。沒有週窗口時不產生經驗值。

- 初次觀察、切換帳號／來源／窗口、重置後首次觀察只建立基準，不補造過去經驗。
- 同週期以已觀察高點去重，避免重複快照與先降後升的數值修正重複得分。
- 一個百分點增加對應 1 XP；同角色跨帳號每日合計上限 20 XP，按本機日期計算。
- Claude、Codex、Antigravity 分開成長；章魚使用三者經驗值平均作為陪伴進度。
  這是遊戲經驗值，不是帳號配額加總，也不是實際 token 統計。
- 0／20／60／150 XP 解鎖四個階段；角色在原畫框內由 88% 長到 100%，
  後續階段有不同柔光，原角色與原視窗尺寸保持一致。減少動態設定不影響進度。
- `pet-growth.json` 原子保存；不存取權杖、帳號明文識別或對話。展示模式使用獨立檔案。

設定顯示角色的等級、經驗與階段進度。無需刻意增加 AI 用量。

## RSS／Atom

v1.31.0 起移至「配額／帳號／任務」旁的獨立「訊息」分頁，採 03 精簡工具列。按「新增來源」才展開網址輸入框；新增成功後自動收起。原設定頁不再放 RSS 區塊，既有來源與暫停狀態保留。
最多 8 個 HTTPS 來源，各來源每 15 分鐘檢查；無需登入、不帶 Cookie。

- 第一輪只記錄基準；後續才接收新項目，不重播舊文章。支援 RSS 2.0、Atom、RSS/RDF。
- 新通知的純文字標題會送到 Google 翻成繁體中文。翻譯最多等兩秒，遇到限流、逾時或其他失敗就顯示原文。譯文快取只放在記憶體。
- 只保留純文字標題、來源與時間；不執行 HTML、腳本或收到的指令，不開啟外部連結。
- DNS 與每次重新導向都檢查目的地，只連公開 IP；固定解析結果，拒絕帳密 URL、
  非 HTTPS、私有位址、DTD／外部實體與過大回應。限制 512 KiB、3 次重新導向及逾時。
- 本機持久化來源與每來源最近 200 個去重摘要。訊息佇列僅在記憶體，最多 50 則；
  超量保留最新並在設定顯示超量數，重啟不補播佇列。
- 有寵物出現且主面板收合時顯示獨立訊息泡，不搶焦點、不改主視窗大小。
  支援上方區域與下方舞台，20 秒後關閉，滑鼠移入暫停；可按 × 提早關閉。
- 任務通知優先；告警小劇場、投食、展開或隱藏時等待。全域暫停訊息會清空佇列，
  各來源可個別停用／移除。預覽訊息不發送網路請求。
